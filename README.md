# 📊 Interactive Sales Performance Dashboard | Microsoft Excel

An interactive Sales Performance Dashboard developed using Microsoft Excel to analyze sales performance, compare sales executives, and track target achievement.

## 📌 Project Overview

The goal of this project was to transform sales data into an interactive and visually understandable dashboard.

The dashboard provides a quick overview of sales performance across different sales executives and cities, along with target achievement metrics.

## 🎯 Project Objectives

- Analyze total sales performance
- Compare sales executives
- Track target achievement
- Identify executives performing closer to or away from their targets
- Analyze city-wise performance
- Present important KPIs through interactive visualizations
- Build a user-friendly Excel dashboard

## 📊 Dashboard Preview

![Sales Dashboard](Sales-Dashboard.png)

## 🔍 Dashboard Features

### 1. Total Sales Analysis

Displays total sales generated by individual sales executives.

### 2. Sales Executive Performance

Provides an executive-wise comparison of sales performance.

### 3. Target Hit Percentage

Shows the percentage of target achieved by each sales executive.

### 4. Away From Target Percentage

Highlights the percentage by which sales executives are away from their target.

### 5. City-wise Filtering

Interactive city filters allow the dashboard to be analyzed for different locations.

### 6. Data Visualization

The dashboard uses charts and visual elements to make sales performance easier to understand.
